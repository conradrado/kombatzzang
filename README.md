# 📖 Introduction

**Kombatzzang (컴뱃짱)**은 컴뱃 스포츠(MMA, 복싱, 무에타이 등)를 즐기는 사람들이
자신의 실력과 지역을 기반으로 적합한 상대를 찾아
시합 및 스파링을 진행할 수 있도록 지원하는 매치메이킹 서비스입니다.

기존에는 SNS나 커뮤니티, 도장 등록을 통해서만 상대를 직접 찾아야 했지만,
Kombatzzang은 사용자의 경기 기록과 레벨을 분석하여
비슷한 수준의 상대를 추천하고 안전하고 효율적인 매칭 경험을 제공합니다.

---

# ✨ Features

### 🥋 실력 기반 매치메이킹
- 경기 및 스파링 기록을 기반으로 사용자 레벨 산정
- 비슷한 수준의 상대 자동 추천
- 지나치게 실력 차이가 나는 매칭 최소화

### 📍 지역 기반 탐색
- 사용자의 활동 지역 기반 상대 탐색
- 가까운 거리의 스파링 상대 추천
- 지역별 활동 유저 확인

### 🏆 전적 관리
- 승 / 패 기록 관리
- 종목별 전적 관리
- 사용자 레벨 및 랭킹 제공

### 📅 경기 모집
- 스파링 모집 글 작성
- 시합 참가자 모집
- 일정 및 장소 관리

### 🧑‍⚖️ 심판 참여 및 기여
- 더 높은 수준의 사용자는 심판으로 참여
- 참여율과 파이터들의 평가에 따라 심판 평점 부여
- 높은 평점을 가진 심판은 서비스 내 재화 획득 (구현 예정)

### 👤 사용자 프로필
- 운동 종목
- 체급
- 활동 지역
- 전적
- 레벨
- 자기소개
