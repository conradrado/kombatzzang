
# 공통 사항 및 원칙
- https://github.com/conradrado/kombatzzang 
    이 프로젝트를 참고하고 이슈를 참조해서 명령을 받고 도메인을 구현하도록

- 하달받은 명령과 관련된 브랜치나 이슈가 없다고 판단되면 이슈/브랜치 생성 및 작업 진행

- dev 브랜치를 기준으로 새로운 브랜치를 checkout

- branch naming convention은 feature/이슈번호-도메인-계층 및 작업내용

- 내가 push 해달라면 origin의 feature로 push

- 작업 범위는 해당 도메인 패키지를 벗어나지 말 것, 벗어나는 경우가 생기는 경우 나한테 물어봐
